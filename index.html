بىۋاسىتە مەنبەدىن

بىر بۇيرۇق بىلەن كۆچۈرۈڭ.

ئامبارنى چۈشۈرۈپ ئېچىڭ. CLI پەقەت تاللانغان قېلىپنى يېڭى قىسقۇچقا كۆچۈرىدۇ؛ بۇيرۇق ئىجرا قىلمايدۇ ياكى بوغچا چۈشۈرمەيدۇ.

تولۇق قوللانما ↗
node bin/create-uyghur.js --template blog --dir ./my-site

npm registry دا ئېلان قىلىش تېخى كۈتۈلۈۋاتىدۇ. بۇ بۇيرۇق چۈشۈرۈلگەن مەنبە كودتا ئىشلەيدۇ.

CLI / 0.2.0

ئۇيغۇرچە UI بۆلەكلىرىنى قوشۇڭ.

يېزىش رامكىسى، كۆزنەك، ئىزدەپ تاللاش، تىزىملىك، يان كۆزنەك ۋە جەدۋەل. ئالتە بۆلەك يەرلىك registry دىن يېڭى قىسقۇچقا كۆچۈرۈلىدۇ؛ قاچىلاش جەريانى تورغا ئۇلانمايدۇ ۋە كود ئىجرا قىلمايدۇ.

UI تەجرىبىخانىسى ↗
node bin/create-uyghur.js --ui-list
node bin/create-uyghur.js --ui writing-field --dir ./my-writing

چۈشۈرۈلگەن مەنبە كودتا ئىجرا قىلىڭ ياكى نەشر بوغچىسىنى قاچىلاڭ.
